# 线下节点

叁仟书屋计划用 **GeoJSON** 描述可以遇见纸本书或守书人的线下节点（咖啡馆、独立书店、公共阅读点等）。

**现在不收录任何点位。** 请不要提交虚构坐标、虚构店名或占位 Feature。

约定（供以后启用）：

- 文件格式：GeoJSON `FeatureCollection`。
- 几何：`Point`，坐标为 `[经度, 纬度]`（WGS84）。
- 属性至少包含：`name`、`type`、`status`。
- 仅收录维护者或贡献者能够核验的真实地点。
- 不在此目录放封面、书目全文或下载链接。

本目录目前仅保留 `.gitkeep`，以便空目录进入版本库。
